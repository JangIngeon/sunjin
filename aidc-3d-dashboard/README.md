# 인터랙티브 인프라 용어사전 · AIDC 3D

충주 데이터센터 평면도(지하1층·1층·2층)를 기반으로 건물 내부 전체를 3D로
모델링한 인터랙티브 학습 대시보드. 카메라·라벨·선택·Flow 모션은
레퍼런스 HTML(용어사전 단일 파일 버전)과 동일하게 구현되어 있다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

## 스택

- React 18 + Vite — UI 셸(헤더/툴바/사이드바)
- three (r169, 명령형) — 3D 뷰포트 (`src/components/Viewport.jsx`)
- Zustand — UI ↔ 3D 상태 공유 (`src/store/useAppStore.js`)

## 모션 (레퍼런스 포팅)

- 좌드래그 궤도 회전 · 우드래그 팬 · 휠 커서 줌(레이캐스트 타깃 이동) · 시점 초기화
- 카메라 이동 중 라벨 페이드 → 정지 260ms 후 방사형 자동 재배치
  (모델 회피 · 리더라인 교차 최소화 · 슬롯 스왑 최적화 — 레퍼런스 알고리즘 그대로)
- 호버: 발광 하이라이트 + 커서 추종 컬러 툴팁
- 클릭 선택: 나머지 회색화(Focus) + 굵은 검정 윤곽선 + 선택 리더 강조 + 사이드바 상세
- 외벽 카메라 방향 자동 페이드 · 상부 슬래브 탑뷰/선택/층필터 연동 페이드
- 배관 온도 그라디언트 + 흐름 패킷(꼬리 4개) 애니메이션, 5계통 개별/마스터 토글

## 건물 구성 (도면 기준)

| 레벨 | 주요 실 |
| --- | --- |
| 지하 1층 | 전기실-1/2(수배전반·변압기), 축전지실, 기계실(칠러·펌프·수처리), 축열조, 공급동 GIS·유류펌프실·RCP실·옥외유류탱크 |
| 1층 | 항온항습실(팬월 갤러리), 전기실1(UPS)·축전지실·전기실2, MMR/MDF(동·서 이중화), 하역장, 상황실·스크린룸, 공급동 로비 |
| 2층 | 전산실(GPU 랙 5열·핫아일 격리·CDU·버스웨이·스토리지·네트워크), 항온항습실, 전기 존(UPS·배터리·PDU), 공급동 비상발전기실(4기)·유류탱크실·소화가스실·사무 윙 |
| 옥상 | 냉각탑 3기, 드라이쿨러 3기, AHU |

층 선택 칩(뷰포트 좌상단)으로 층별 아이솔레이션 뷰를 볼 수 있다.
